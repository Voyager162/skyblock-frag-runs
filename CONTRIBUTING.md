# Contributing

Use Java 25 and the included Gradle wrapper. Run `./gradlew test build` (or `gradlew.bat test build` on Windows) before submitting changes.

Report bugs through GitHub Issues with the Minecraft, Fabric API, loader, and mod versions, the steps to reproduce, and expected versus observed behavior. For tracking issues, include the relevant scoreboard/chat formats and whether the run ended normally or early. Remove account tokens, personal information, and unrelated chat from logs before sharing them.

Keep accounting changes covered by tests for duplicates, missing data, and interrupted runs. Document any changed assumptions about Hypixel signals. Do not claim live dungeon validation without actually performing and describing that playtest.

The project uses the MIT license. The initial code and documentation were AI-generated; contributions should be reviewed and tested on their merits.
